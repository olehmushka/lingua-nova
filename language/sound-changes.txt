# Sound changes: proto-language → modern language.
# Rules apply top to bottom; order matters.
#
# Syntax (parsed by internal/sound; `lnova rules` lists what it read):
#   target > replacement / environment
#   _   the position of the target
#   #   word boundary (only at the outer edge of the environment)
#   V   any vowel, C any consonant (categories from phonology.yaml)
#   ∅   nothing (deletion)
# The "/ environment" part is optional (rule 3 has none).
# A line starting with # is a comment. There are no comments after a rule,
# because # inside a rule means the word boundary.
#
# Rules use the romanized spelling. Digraphs (lh, nh, ch) count as ONE sound.
# Each line is one rule; traces identify it by its line number.
#
# Application is SIMULTANEOUS: a rule finds all its matches in the word as it
# was before the rule ran, then rewrites them all at once. A change can't
# create a new match for the same rule: a > e / e_ turns eaaa into eeaa,
# not eeee. Matches don't overlap.
#
# STARTER RULES (draft, expect to tune them as the lexicon grows)

# 1. Palatalization: consonant + i before a vowel merges into a palatal.
#    proto *falia → falha, *sunio → sunho
li > lh / _V
ni > nh / _V
si > x  / _V
zi > j  / _V
ti > ch / _V
ci > ch / _V

# 2. Intervocalic voicing (the hallmark of Western Romance: Latin vita → Portuguese vida).
#    proto *pata → pada
p > b / V_V
t > d / V_V
c > g / V_V

# 3. Degemination: double consonants become single.
#    Must come AFTER rule 2, so *patta → pata (the t stays voiceless).
#    Swap the order and every tt would become d. This is why order matters.
pp > p
tt > t
cc > c

# 4. Final nasals are lost (no nasal endings in the modern language).
#    proto *saman → sama
n > ∅ / _#
m > ∅ / _#

# 5. Geminate affricates simplify: a stop left before ch merges into it.
#    Rule 1 turns the second half of a geminate into ch (*pattia → patcha)
#    and so bleeds rule 3, which no longer sees tt. This rule cleans up:
#    *pattia → pacha, *luccio → lucho. *pattia and *patia now merge.
t > ∅ / _ch
c > ∅ / _ch

# 6. A stop or f before lh is lost. Rule 1 turns the l of a pl bl cl gl fl
#    onset into lh when i + vowel follows, and plh, clh... are not legal
#    onsets: *plia → plha → lha, *aclio → aclho → alho.
p > ∅ / _lh
b > ∅ / _lh
c > ∅ / _lh
g > ∅ / _lh
f > ∅ / _lh
